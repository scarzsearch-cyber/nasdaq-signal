## 2. 판정 — 네 갈래
### 확인된 구현 오류
- **없음** — 판정 결과(verdict·rc)를 규약과 어긋나게 내는 입력을 찾지 못했다(경계 12쌍 · 보류 · 간격 · 등록 전후 · R · 지문).
- 코드 주석 1건(값 영향 0): `evaluate_oos` 의 `seg = roll[i0:]  # 창 끝이 동결 이후인 것만` — 실제로는 **창 시작이 동결 이후**(동결 안에 완전히 든 창)이고, 그것이 규약 「동결+756 뒤부터」와 맞는 쪽이다. 주석만 틀렸다.

### 규약이 모호한 부분(코드는 한 해석을 택했다 · 소유자/돈전략 결정)
1. **종속 사건의 A 실패(C05)** — 평가기는 A 의 「역사 밖」을 **독립 사건만** 판정에 넣는다(등록 8/8 이 독립 기준이라 규약과 정합). 그러나 종속 사건 줄에도 `A 재난 지급 ★역사 밖` 을 그대로 찍어, 사람이 읽는 줄과 최종 판정(「재검토 사유 없음」)이 어긋난다. 파수꾼은 마지막 판정 줄만 읽어 거짓 알림은 없다. **최소 제안**: 종속 사건 줄에 「(종속 — A 판정 제외)」를 붙이거나, 종속 사건도 A 에 넣을지를 규약에 명시.
2. **R 은 상태 기반(C18)** — 동결 이후 창 중 최저가 −49.3% 아래(역사 밖)였어도 **현재 창**이 정상이면 판정 「정상」이다(최저는 출력에만). JSON `judgment.combination` 「어느 관문이든 역사 밖 1건 → 재검토」· R 「상시」 문구와는 결이 다르다. 주간 파수꾼 실행 사이(월~월)의 창은 어디에도 남지 않는다. **최소 제안**: `seg.min()` 에도 문턱을 걸거나(과거 창 역사 밖 = 재검토), 「현재 창만」이 의도면 규약 문구에 그렇게 적는다.
3. **자기검산의 역사 집합이 열려 있다(C15)** — 「역사」= 날짜 < 동결 **이고 창이 찬** 사건. 등록 때 창이 안 찼던 동결 이전 사건은 등록값에 없다가 자료가 자라면 편입돼 「기저율 표류 → 판정 중단」이 난다. **실제 등록에는 해당 없음**(E2: 마지막 도피 2025-04-16 은 등록 자료 끝 2026-08-28 에 창이 차 있었다 · 미충족 0건). 다음 재등록 때의 규약 후보: 「동결 −252 거래일 이전 사건만 역사」 또는 「재등록은 동결 이전 창이 전부 찬 뒤에」.
4. **장부 ↔ 엔진 대조 부재(C23·E3)** — JSON `event.definition` 은 「장부 `state` QLD→SCHD 에 대응」이라 적지만 평가기는 `oos_log.csv` 를 읽지 않고 엔진(달러 모형 · 월간 연장 자료)에서 사건을 재구성한다(JSON `engine.why` 가 그 설계를 명시). 따라서 장부의 누락·중복·순서는 판정에 영향 0 이고, 반대로 **장부 전환일과 엔진 도피일이 갈려도 아무도 모른다**(신호 캐시 adjclose vs 백테스트 캐시 비수정 — v201 이 27년 중 11일 갈림을 실측). 엔진 자료가 장부보다 최대 5주 뒤처지므로 사건 직후 파수꾼 「사건 0건 — 이상 없음」은 「아직 모른다」에 가깝다. **최소 제안**: 파수꾼 `check` 또는 평가기 출력에 장부 전환일 vs 엔진 도피일 읽기 전용 대조 한 줄(도구 E3 구현 참조) — deploy 수정이라 소유자 승인.
5. **보류 사건도 「사건 N건」(C11)** — 창 미충족 사건은 판정에 안 쓰지만 「동결 이후 도피 사건 N건」에 든다 → 파수꾼 `사건 1건 — 재검토 사유 없음`(ok) → 화면 「판정 규약 사건 1건 — 이상 없음」. 「판정된 것이 없다」와 「판정해서 이상 없다」가 같은 문구다. **최소 제안**: 출력에 「판정 보류 N건」을 따로 찍고 파서가 그 수를 이월.
6. **자기검산 허용 오차** — P05 는 ±0.01(1%p) 안이면 통과, A 는 1건 차이도 중단. 원자료 재조정으로 P05 가 0.9%p 움직여도 판정이 계속된다 — 설계 선택으로 보이나 규약에는 적혀 있지 않다.

### 정상 확인
- 관문 부등호 방향·경계(A ≤ −50% 적용 · B 가 엄격히 얕아야 통과 · B/R 「<」 엄격) · 창 충족 경계(i+252 == n−1 판정 · == n 보류) · 독립 간격(252 초과 · 직전 도피 기준 연쇄) · 동결일 포함 · 지문 불일치·기저율 표류 → rc 2 판정 없음 · 사건 0 문구 · 파수꾼 파서 계약 문자열(E0) · **등록값 독립 재계산 일치(E1)** · 실제 역사 + 합성 OOS 사건의 판정(E4).
- 정확히 경계값(−0.293 · −0.411)은 부동소수점에 달린다(C06x 정상 · C08x 역사 밖) — 실측 보험료가 소수 셋째 자리 등록값과 정확히 같을 확률은 0 에 가깝고 규약이 「<」라 결함 아님.

### 미검증
- idx 정렬·중복 없음은 엔진 전제로 두었다(합성은 정렬 영업일). 실제 동결 이후 **사건 자체가 0건**이라 실 사건 경로는 합성으로만 봤다. 파수꾼 주간 실행에서의 평가기 호출은 월요일 09:10 KST 관찰 항목(세션 예약). 타 시장·통화·비용 변형은 규약 밖.
