## 3. 작업 규약 (구현까지 할 경우)

- **기본 모드는 분석·제안 보고다.** 코드를 고치기 전에 [현재 구조 / 개선안 / 수정 파일 /
  전략 로직 변경 0건] 형식으로 계획을 먼저 보고하고, 사용자가 승인한 항목만 구현한다.
- 구현 후 필수: `python verify_all.py --fast` 실패 0 · 412px 가로 스크롤 0 ·
  콘솔 오류 0 · 기존 localStorage 키(`b_port_v1`, `b_trades_v1`, `b_view_v1`,
  `b_chk_*`, `qqq_signal_*`) 구조 유지.
- 커밋 규칙: signal.html 을 바꾸는 커밋 제목에는 반드시 `vNN` 버전을 넣는다
  (배포 시 화면의 "전략 반영 vNN" 표기가 커밋 제목에서 뽑힌다). 작업 전 `git pull`.
- 커밋 메시지에 큰따옴표를 쓰지 마라 (PowerShell 5.1 이 인자를 쪼갠다).
