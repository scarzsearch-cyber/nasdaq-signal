# 나스닥 신호 시스템 — 개선 아이디어 요청 프롬프트 (외부 AI용, v91 기준)

> 사용법: 아래 전체를 ChatGPT·Gemini 등에 붙여넣는다. 시스템이 바뀌면 이 문서를 갱신한다.
> 외부 AI의 답은 "아이디어 후보"일 뿐이며, 구현 전에 반드시 이 저장소를 아는 도구가 검증한다.

---

당신은 UX/제품 컨설턴트다. 아래 시스템의 **기능 개선·웹 UI 최적화 아이디어**를 제안하라.
당신은 이 시스템의 코드를 본 적이 없다. 그러므로 **아래 컨텍스트에 없는 내부 구조를
추측해서 단정하지 말고**, 추측이 필요하면 문장 앞에 `[가정]`을 붙여라.

## 1. 시스템 개요 (사실 — 절대 바꿔 말하지 말 것)

- 개인용 투자 신호 웹. GitHub Pages 정적 호스팅, 페이지 2개:
  **signal.html**(오늘의 신호 — 매일 보는 화면) + **guide.html**(설명서).
- 전략 B (동결됨 2026-08-27, 어떤 개선 제안도 금지):
  QQQ(미국)의 252거래일 고점 대비 낙폭이 **−16% 이하로 마감 → 전량 방어 /
  −16% 위로 회복 마감 → 전량 공격**. 연 2~3회 전환.
- **공격 포지션 = TIGER 미국나스닥100레버리지(합성) 418660 · 100%**
- **방어 포지션 = TIGER 미국배당다우존스 40% + TIGER 미국채10년선물 40% +
  ACE KRX금현물 20%** (주의: 방어에 레버리지 ETF 는 0%다. "레버리지 40% 유지"
  같은 구성은 존재하지 않는다 — 과거 외부 AI 가 이걸 틀렸다.)
- T4 그림자: 보조 후보 전략을 "기록만" 하는 중 (승격 안 됨, 판정은 몇 년 뒤).
  화면에서는 참고 패널 하나. 이것도 변경 제안 금지.
- 신호는 미국 종가 확정 후 **새벽에 자동 갱신**(GitHub Actions), 실패 시 카톡 알림.
  실제 매매는 같은 날 한국장 09:05~15:20 에 **사용자가 수동으로**.

## 2. 기술 제약 (아이디어가 이 안에 있어야 채택 가능)

- 정적 사이트: 서버·DB·로그인 없음. 바닐라 JS/CSS 한 파일씩.
- 데이터: 저장소의 JSON/CSV 를 fetch (신호·통계·국내 ETF 전일종가/괴리율·한국 공휴일).
- 사용자 입력(보유·체결 등)은 **localStorage** — 기기 간 동기화 없음.
- 주 사용 환경: **갤럭시 412px 세로 모바일**. 가로 스크롤 금지,
  세로 길이 최소화 강한 선호("한눈에"), 폰트 축소보다 요소 제거 선호.
- 자동매매 금지. "T4가 더 좋다" 같은 투자 판단 문구 자동 생성 금지.
- 외부 API 호출 추가는 신중히 (무료·무키·CORS 가능해야 함).

## 3. 이미 구현된 것 (중복 제안 = 감점)

signal.html (위에서 아래 순서):
0. **루틴/전체 보기 토글** (기본 루틴 = 신호 카드+포트폴리오만, 선택 저장) ·
   조정 필요 시 **주문 메모 복사** 버튼(클립보드 — MTS·카톡용). (v91)
1. 상단: 종가 기준일 + 자동갱신 시각 + 전략 버전 + 규칙 동결 배지, 신선도 경고(2거래일+).
2. 시장 시계: 미국장/한국장 카운트다운, 휴장·서머타임·조기마감 반영.
3. 신호 카드: 낙폭 눈금자, 공격/방어 판정, 보유할 상품(코드 포함), 전환되면 살 것
   3종, **"오늘 할 일 없음" 한 줄**, 전환일엔 전환 안내 + **실행일 자동 계산
   (한국 휴장 반영) + 실행 체크리스트 3항목**, 낙폭·고점·전환 기준가·여유 %p,
   임계 거리 게이지(여유/접근/근접).
4. 수동 종가 입력(접힘 — 자동 갱신 실패 시 백업, CSV 업로드 포함).
5. **내 포트폴리오**: 보유 수량·평단·현재가 입력(현재가 기본값 = 자동 수집 전일 종가)
   → 현재 vs 목표 비중 막대(목표 마커) → 필요한 매도/매수 금액·정수 주수 →
   조정 후 예상 현금 → 평단 손익 → 경고(음수/가격 누락/오래된 입력).
   **체결 기록**(접힘): 기록하면 보유 자동 반영 + 기준가 대비 차이% (실측 비용 표본).
6. 포지션 계산기: 신규 자금 원금 → 종목별 목표금액/주수/잔여현금.
7. 규칙 카드 + 지표 6종 + 지표 풀이(쉬운 말 번역).
8. 참고: 한국장 실행 시각 안내, 성과 비교표(전략 4변형 × 기준 3개, 모바일 sticky),
   같은 기간 비교표, ISA 계좌 가이드, 위기 궤적 차트(닷컴/2008/코로나/2022 겹침),
   T4 그림자 패널.
9. guide.html: 30초 요약, 루틴, 반드시 이해할 6가지(보유기간별 원금손실 표 포함),
   전략 선택 기준, 자산 단계별 진로, T4 쉬운 설명, 동결 이유, 자동화 목록, FAQ.

## 4. 알려진 공백 (아이디어 환영 영역)

- localStorage 라 폰↔PC 동기화 없음 (서버 없이는 어려운 것 알고 있음 — 창의적 대안?)
- 카톡 알림에 "필요 매매 금액"은 아직 미포함 (보유 정보가 서버에 없어서).
- 체결 기록이 쌓이기 전까지 호가 스프레드 실측 없음.
- 다크 모드 없음 (라이트 고정).
- 접근성(스크린리더 등) 점검 안 됨.

## 5. 요청 — 이것만 답하라

A. **UI/UX 개선 아이디어** (전략·수치 변경 없이 인지 부담·클릭·실수를 줄이는 것)
B. **기능 아이디어** (§2 제약 안에서 — 정적 + localStorage + 무서버)
C. 각 아이디어마다 다음 형식:
   - 제목 / 무엇을 / 왜 (어떤 사용 순간의 어떤 불편) / 예상 효과
   - 구현 난이도 (상·중·하) / §2 제약과 충돌 여부 / §3 과 중복 아닌지 확인
D. 마지막에: 위 §3 중 **오히려 빼거나 접는 게 나은 요소** 톱 3 (이유 포함).
