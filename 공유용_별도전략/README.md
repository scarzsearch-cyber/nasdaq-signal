## 왜 따로 뒀나 (소유자 지시, 2026-09-02)

소유자가 **본 전략을 작업하던 다른 세션에서 이 `.py` 파일들을 우연히 발견하고
「이건 뭔지」 분석하기 시작한 실사고**가 있었다. `research/` 안에 섞여 있으면
연구 자산으로 오인되어 **본 전략에 손상을 입힐 위험**이 있다. 그래서 폴더로 격리했다.

- `research/` 에 두지 않는다 → `verify_all.py` 의 FILES.md 관문(v172) 감시 범위 밖이다.
  **의도된 것**이다. 이 폴더는 전략 문서 체계의 일부가 아니다.
- 파일명은 전부 `share_variant_*` 접두사를 유지한다 — 어디서 보든 정체가 드러나게.

## 읽기 전용 의존 (건드리지 말 것)

이 스크립트들은 저장소의 검증된 엔진을 **읽기만** 한다 — 수정하지 않는다:
`hist_defensive.py` · `hist_defasset.py` · `research/eng_common.py` · `data/hist/*`

경로 보정 헤더가 `_ROOT`(= 이 폴더의 부모 = 저장소 루트)를 잡고 `research/` 를
`sys.path` 에 넣는 구조라, **이 폴더가 루트 바로 아래 한 단계**에 있는 한 그대로 돈다.
폴더를 더 깊이 옮기면 임포트가 깨진다.

## ★ 파일 이름 규칙 — 「이 파일 뭐야?」를 두 번 겪지 않기 위해

**실사고(2026-09-02)**: 이 폴더에서 계산하던 세션이 `_inject.py` 라는 1회용
스크립트를 만들었다가 지웠는데, 그 몇 초 사이에 다른 세션의 감시에 걸려
「이건 뭐냐」가 됐다. 파일이 이미 사라진 뒤라 정체를 확인할 수도 없었다.
아래 두 줄이면 재발하지 않는다.

### 1) 중간 산출물은 **반드시 `_` 로 시작한다**

`.gitignore` 가 `공유용_별도전략/_*.json` 만 무시한다. `_` 를 안 붙이면
저장소에 그대로 들어가고, 다음 사람이 또 「이 파일 뭐야?」를 겪는다.

```
공유용_별도전략/_무엇이든.json     ← 자동 무시됨 (O)
공유용_별도전략/결과.json          ← 커밋 대상이 됨 (X)
```

### 2) **1회용 스크립트는 저장소 안에 만들지 마라**

계산 결과를 어딘가에 밀어넣는 「쓰고 버릴 코드」는 **저장소 밖 임시 폴더**에서
돌린다. `research/` 든 여기든, 저장소 안에 만들었다 지우는 것 자체가
다른 세션의 감시를 건드린다 — 몇 초라도 마찬가지다.

- 남길 가치가 있는 계산 → `share_variant_*.py` 로 **이름 붙여 커밋**한다.
- 한 번 쓰고 버릴 것 → **저장소 밖**에서 돌린다. 여기에 만들지 않는다.

## 결과 요약 (참고용, 전략 아님)

- **롤링 10년 320창(1990~)**: 섞은 쪽의 중앙값이 QQQ 단독보다 높고(13.65% vs 12.68%),
  QQQ 단독은 10년을 통째로 **−8.14%/년**으로 끝낸 적이 있다(손해로 끝난 10년 8.4% vs 섞으면 0.3~3%).
- **전 구간 36.7년**: SCHD 와 QQQ 의 Calmar 가 **둘 다 0.176 으로 동일**하고,
  5개 배합이 전부 그보다 높다(S5Q5 0.239).
- **국면은 갈린다**: 잃어버린 7년(2000.03~2007.10) SCHD **+140.6%** vs QQQ **−51.1%** /
  기술주 대세상승(2009~2020) SCHD +531% vs QQQ **+849%**.

※ 「최근 10/20/30년」 트레일링 토글은 **폐기했다**(2026-09-02) — 셋 다 끝점이 오늘이라
같은 강세장을 세 길이로 자른 것이었고, SCHD 가 무조건 후진 자산처럼 보이게 만들었다.

**이 결과를 본 전략에 적용하지 마라.** 자산도 신호도 방어도 전부 다른 물건이다.
