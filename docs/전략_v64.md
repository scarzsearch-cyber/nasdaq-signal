# 전략 v64 — 지표 풀이를 네 줄로 끊고 값에 강조색

작성 2026-08-28. 관련 `signal.html` · `verify_all.py` I5.

## 0. 답

> **v62·v63 이 풀이를 붙였는데 한 칸 안에서 이어 써서, 어디까지가 정의고
> 어디부터가 수치인지 안 보였다.** 네 줄로 끊고 값에 강조색(`--attack #0B5FD6`)을 줬다.
>
> 그리고 **MDD 의 방향 표시가 틀렸다** — 「↑ 클수록」이었다.

---

## 1. 한 칸 = 네 줄

```
CALMAR                    ↑ 클수록      ← 이름 + 방향
낙폭 대비 효율 — 일시적 대폭락 위험을 본다   ← 뜻

0.547 — 최악의 낙폭을 1.8년치 수익으로 메움  ← 지금 값이 뜻하는 것 (강조색)
2배 그냥 보유는 5.5년치                    ← 눈금 (작고 흐리게)
```

| 줄 | 클래스 | 스타일 |
|---|---|---|
| 이름 + 방향 | `.nm` + `.ar` | 15px 700 ink · 방향은 12px muted |
| 뜻 | `.df` | muted |
| **지금 값** | `.rd` | ink, 숫자는 **`--attack` 700** |
| 눈금 | `.bm` | 13px muted |

---

## 2. MDD 의 방향 표시가 틀렸다

방향을 `UP`/`DN` 두 가지로만 두고 MDD 를 `UP`(클수록)에 넣었다.
**숫자로는 맞다** — −44% > −56% 이니 큰 쪽이 낫다.
**그런데 사람은 「MDD 는 클수록 좋다」로 읽는다.** 정반대다.

지표마다 자연스러운 말로 바꿨다:

| 지표 | 전 | 후 |
|---|---|---|
| 최종배수 | ↑ 클수록 | ↑ 클수록 |
| **MDD** | **↑ 클수록** | **↓ 얕을수록** |
| **회복기간** | ↓ 작을수록 | **↓ 짧을수록** |
| CALMAR · SORTINO | ↑ 클수록 | ↑ 클수록 |
| ULCER | ↓ 작을수록 | ↓ 작을수록 |

---

## 3. ULCER 설명에서 정의문을 뺐다

**전**: `늘 얼마나 물속이었나 — 낙폭의 제곱평균. 작을수록 좋음`
**후**: `늘 얼마나 물속이었나 — MDD 가 못 보는 평상시의 고통`

「제곱평균」은 **정의**지 설명이 아니다. 계산식은 `docs/전략_v60.md` 에 있고,
화면에는 **무엇을 재는지**만 둔다.

**I5 에 검사를 넣었다** — 화면에 `낙폭의 제곱평균` 이 다시 나타나면 실패한다.
