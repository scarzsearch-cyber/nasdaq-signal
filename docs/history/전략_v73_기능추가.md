## 2. 데이터 게이트·알림의 동작 규약

- 게이트는 **붙이려는 새 구간**(+이음새)을 검사한다. 실패 시: 그 파일만 갱신 거부(기존
  정상 데이터 유지) → 전체 종료코드 1 → monthly workflow 의 다음 스텝(build_stats)이
  실행되지 않으므로 signal.json·stats·문서 등 downstream 이 오염될 경로가 없다.
- 금리(^TNX)는 ±30% 검사 제외 (2020-03 실제 −40% 일변동), 공백 허용 12일(연휴 커버).
- 알림 실패는 파이프라인을 다시 실패시키지 않는다 (부가 기능 원칙).

## 3. 화면 — 임계 게이지·계산기·고정열

- **임계점 거리 게이지**: 신호 계산이 만든 `o.dd`/`o.gap_pp` 만 사용(별도 계산 없음).
  여유(노랑, ≥8%p) → 접근(주황, 3~8) → 근접(빨강, <3) → **방어 트리거 발생**(돌파 시
  게이지 대신 상태 명시). 접근/근접에선 "주문할 방어 바스켓 확인" 경고문 — **예측이
  아니라 거리 표시**임을 문구에 못박음 (패턴 유사도 경고는 v58·v59 기각 사유로 비채택).
- **포지션 계산기**: 원금 입력 → 자산별 목표금액·매수 주수(내림)·잔여 현금.
  상품 구성은 `signal.json` 의 risk/defensive 설정에서 읽음(하드코딩 없음), 전략 2종
  (채택안/헤지 60/40) × 상태(공격/방어). 가격은 직접 입력 — 출처·계산 시각 표기.
- **모바일 고정열**: ≤700px 에서 기준·전략명 열 `position:sticky`.

## 4. 화면 — 표 재편 (소유자 요청)

- 성과 비교: 벤치마크 2줄 삭제(데이터는 JSON 유지), 기준 3개만(us_2000/kr_1997/kr_real),
  전략 4줄: 채택안 / 배당100 / **헤지 60/40·방어 40/40/20 ★추천(파랑)** / 헤지·배당100.
- 지평표: 기준 2개(us_2000/kr_1997), 2배 보유 대신 **헤지 60/40(추천·파랑)** 병기.
- 강조 위계: **파란 볼드(최중요) > 볼드 > 일반** — 급락 무방비 경고·세로비교 금지·
  체결 시간대 등 6곳에 적용.
