## 2. A. Episode Oracle — 타이밍 잠재력은 거대하다

각 폭락에서 **사후적으로 최적 복귀일**을 골랐다. 실전 전략이 아니라 상한선이다.

| | ISA중앙 | P20 | P5 | 영구중앙 | MDD | 전환 |
|---|---:|---:|---:|---:|---:|---:|
| **현행 −16/−16** | 70.9 | 35.7 | 25.9 | 25.0 | −60.5% | 140 |
| **Episode Oracle** | **801.2** | **404.4** | **220.6** | **243.6** | **−49.0%** | **96** |

**+1030%.** v58 의 Meta Oracle(+288%)보다 훨씬 크다.
**규칙을 갈아타는 것보다 한 폭락 안에서 복귀일을 맞히는 게 잠재력이 3배 이상 크다.**

### 2-1. 그런데 그 최적일이 어디에 있나 (§35/§37)

| | |
|---|---:|
| Oracle 복귀일 − **현행** 복귀일 (중앙) | **−2일** |
| 〃 평균 | −8일 |
| 〃 **표준편차** | **41일** |
| 현행보다 빨리 나간 episode | **61 / 70** |
| Oracle 복귀일 − 그 폭락 **저점** (중앙) | **+0일** |
| 〃 표준편차 | **39일** |
| 〃 범위 | **−10 ~ +262일** |

**최적 복귀일은 곧 "그 폭락의 저점"이다.** 당연하다 — 바닥에서 사는 게 최적이다.

**현행은 중앙값 기준 그 저점의 2일 뒤에 돌아간다.** 놀랍도록 가깝다.

> **문제는 중앙값이 아니라 산포다.** 표준편차 41일, 범위 −10 ~ +262일.
> **어느 폭락이 즉시 나가야 하고 어느 폭락이 1년을 기다려야 하는지**를
> 사전에 구분해야 하는데, 그게 이 연구의 나머지가 실패한 지점이다.

## 3. B. Forward risk — 예측은 되지만 쓸 수 없다

"앞으로 20일 안에 추가 −10%" 확률을 워크포워드(10년→1년)로 추정했다.

### 3-1. G13 보정 (§27) — 아주 약하다

| | |
|---|---:|
| 기저확률 | 8.2% |
| Brier | 0.0743 |
| 상수예측 Brier | 0.0749 |
| **개선** | **0.9%** |

| 예측확률 | 표본 | **실제 빈도** | 평균 예측 |
|---|---:|---:|---:|
| 0~10% | 9,363 | 5.3% | 3.6% |
| 10~20% | 718 | 15.7% | 13.6% |
| 20~35% | 286 | 27.6% | 26.3% |
| **35~50%** | 223 | **17.9%** | 42.1% |
| **50%+** | 479 | **35.7%** | **63.8%** |

**낮은 확률 구간은 잘 맞고, 높은 확률 구간에서 심하게 과신한다.**
64% 라고 예측한 날의 실제 발생률이 36% 다.

**"위험하다"고 크게 외칠 때가 가장 부정확하다** — 전략에 쓰기 최악의 성질이다.

### 3-2. 전략으로 바꾸면

| | ISA중앙 | P20 | P5 | 전환 |
|---|---:|---:|---:|---:|
| 현행 | **70.9** | **35.7** | **25.9** | 140 |
| 위험확률 <15% 복귀 | 69.2 | 34.9 | 24.9 | 134 |
| 위험확률 <25% · <35% | **무발동** | | | 140 |

**문턱 25%·35% 는 무발동이다** — 도피 중 예측확률이 그 위로 올라가는 날이 거의 없다.
15% 로 낮추면 발동하지만 **전 지표에서 진다.**

## 4. C·D — 나머지 두 축

| 전략 | ISA중앙 | P20 | P5 | MDD | 전환 |
|---|---:|---:|---:|---:|---:|
| 현행 | **70.9** | **35.7** | **25.9** | **−60.5%** | 140 |
| **C CUSUM k=3** | 36.2 | 18.0 | 11.7 | **−82.0%** | **366** |
| **C CUSUM k=5** | 7.3 | 1.4 | 1.1 | **−98.7%** | 140 |
| D 반등의질 5% | 43.9 | 22.2 | 14.0 | −58.6% | 80 |
| D 반등의질 8% | 41.9 | 20.8 | 14.3 | −54.0% | 74 |

**C 변화점 탐지는 재앙이다.** k=5 는 MDD −98.7% 로 **2배 그냥 보유와 같다** —
통계적 단절이 확인될 때쯤이면 이미 다 떨어져 있다.

**D 반등의 질도 −38~41% 로 진다.** 「저점대비 5~8% 회복 + 신저점 없음 + 변동성 완화」를
**추가 조건**으로 걸면 복귀가 늦어지고, v49 의 모멘텀 확인과 **같은 이유로** 진다.

> **§37 의 trade-off 가 또 확인됐다** — 조기 복귀는 V자를 잡고 데드캣에 당한다.
> 확인 조건을 붙이면 데드캣은 피하지만 V자를 놓친다. **양쪽을 동시에 얻는 방법이 없다.**

## 5. E. CVaR — 뜻밖에 현행이 1위다

하위 5% **평균**(꼬리손실)으로 격자 210개를 다시 줄세웠다.

| 순위 | 규칙 | CVaR5 | ISA중앙 | P5 |
|---:|---|---:|---:|---:|
| **1** | **−16/−16 (현행)** | **24.7** | **70.9** | **25.9** |
| 2 | −16/−15 | 22.5 | 64.3 | 24.6 |
| 3 | −17/−15 | 22.3 | 58.8 | 23.9 |
| 4 | −20/−18 | 21.1 | 66.2 | 22.2 |

**현행의 CVaR5 순위 = 1위 / 210.**

§7~§9 는 "꼬리손실을 목적함수로 쓰면 다른 답이 나오는가"를 물었다.
**답은 "같은 답이 나온다"다.** CVaR 축은 새 후보를 만들지 못하고 **현행을 재도출한다.**

> **주의**: 이건 v56 이 지적한 "전체 표본 1위"와 같은 계열이다.
> 다만 **CVaR 은 현행을 고를 때 쓰지 않았던 목적함수**이므로 약한 방증은 된다.
> 강한 증거는 아니다.

## 7. §40 에 대한 답

> **"현행의 우위가 좋은 문턱 하나를 찾은 것인가, 아니면 실시간 추정으로
> 더 좋은 타이밍을 할 수 있는가?"**

**둘 다 아니다. 세 번째 답이 나왔다.**

| | |
|---|---|
| 좋은 문턱을 찾은 것인가 | **부분적으로.** 다만 CVaR 기준 1위/210 이라 목적함수를 바꿔도 같은 답이 나온다 |
| 실시간 추정으로 더 잘할 수 있나 | **아니다.** 5개 축 전부 실패 |
| **그럼 현행은 무엇인가** | **최적 복귀일(=저점)의 중앙값에서 2일 뒤에 서 있는 규칙** |

**현행이 잘하는 건 "언제 나갈지 맞히는 것"이 아니라
"평균적으로 저점 근처에 서 있으면서 크게 틀리지 않는 것"이다.**

산포(표준편차 41일)를 줄이려면 **어느 폭락인지 구분**해야 하는데,
v51~v59 가 시도한 모든 방법(VIX·breadth·국채·신용·RV·변화점·예측모형·반등의 질)이
그걸 못 했다.
