## 1. 왜 이 전략에 계좌가 특히 중요한가

**이 전략은 원화 기준 연 2.1회 전량 전환한다.** 국내 상장 해외 ETF는

- 매도할 때마다 매매차익에 **15.4% 원천징수**
- 매매차익이 배당소득으로 과세되어 **손실 통산 불가**
- 연 2,000만원 초과 시 **금융소득종합과세** (최대 49.5% 누진)

전환할 때마다 복리의 원금이 깎인다. **전환이 잦은 전략일수록 과세이연의 값이 커진다.**

## 2. 방법

| 항목 | 값 |
|---|---|
| 납입 | 연 2,000만원(월 1,666,667원) × 5년 = 1억. **ISA 한도상 거치식이 불가능하다** |
| 그 뒤 | 추가 납입 없이 보유 |
| 기초 | 원화 · 환노출 2배 · 방어 40/40/20 · 한국 거래일 체결 |
| 비용 | 편도 수수료 0.1% + 슬리피지 0.1% |
| 방어 분배율 | 1.3% (배당 다리 40% × 3.3%) |
| 창 | 롤링 10/15/20년, 1981-04~ (환율 데이터 시작) |

### 4단계 분해 — ISA 이득이 어디서 오는가

| 단계 | 정의 |
|---|---|
| ① 일반계좌 | 전환마다 15.4%, 손실 통산 없음, 방어 분배금 과세 |
| ② 이연만 | 계좌 안에서는 무과세, 해지 시 한 번 15.4% |
| ③ 이연 + 9.9% | 해지 시 한 번 9.9% |
| ④ ISA 서민형 | ③ + 순이익 400만원 비과세 |
| ⑤ ISA 3년 해지 | 3년마다 정산(400만원 비과세는 매번 받음) 후 재가입 |

## 3. 결과 — 납입 1억 대비 세후 평가액 (롤링 창 중앙값)

| 계좌 | 10년 | 15년 | 20년 | 실효세율 |
|---|---:|---:|---:|---:|
| 세전 (참고) | 6.84배 | 31.3배 | 151.6배 | — |
| **④ ISA · 만기 연장** | **6.27배** | **28.3배** | **136.7배** | **9.9%** |
| ③ 이연 + 9.9% | 6.26배 | 28.3배 | 136.7배 | 9.9% |
| ⑤ ISA · 3년마다 해지 | 5.96배 | 25.0배 | 115.2배 | 10.7% |
| ② 이연만 (15.4%) | 5.94배 | 26.7배 | 128.4배 | 15.4% |
| ① 일반계좌 | 5.97배 | 23.6배 | 91.8배 | 16.9% |

**일반계좌 대비: +5.0% (10년) / +20.2% (15년) / +48.8% (20년).**

> 10년 창에서는 ②(이연만)가 ①(일반계좌)보다 근소하게 **나쁘다**(5.94 vs 5.98).
> 전환비용이 이연 이득을 상쇄하는 구간이 짧은 창에 있다. 세율 인하(③)까지 가야 뒤집힌다.
창이 길수록 벌어진다 — 이연된 세금이 계속 복리로 굴러가기 때문이다.

### 분해 (20년 창)

| 요소 | 기여 | 비중 |
|---|---:|---:|
| **과세이연** (①→②) | **+39.8%** | **82%** |
| 세율 15.4% → 9.9% (②→③) | +6.5% | 13% |
| 400만원 비과세 (③→④) | +0.0% | 0% |
| **합계** | **+48.8%** | 100% |

**400만원 비과세는 이 규모에서 사실상 0이다.** 순이익이 수억 단위가 되면
400만원은 반올림 오차다. **실효세율은 9.9%로 수렴한다.**

> ISA를 "400만원 비과세 받는 계좌"로 이해하면 값어치를 완전히 잘못 잡는다.
> **이 전략에서 ISA는 과세이연 계좌다.**

## 4. 3년 만기 — 연장이 해지보다 15% 낫다

| | 20년 창 중앙값 | 일반계좌 대비 |
|---|---:|---:|
| **만기 연장해 끝까지 보유** | **136.7배** | +48.8% |
| 3년마다 해지·재가입 | 115.2배 | +25.4% |

3년마다 해지하면 400만원 비과세를 **여러 번** 받지만, 그걸로도 과세이연 손실을 못 메운다.

**그리고 모형이 잡지 못한 더 큰 함정이 있다.** 해지하면 불어난 돈을 다시 ISA에 넣을 수 없다 —
**재납입도 연 2,000만원 한도**다. 1억이 3억이 된 뒤 해지하면 3억을 다시 못 넣는다.
위 ⑤는 그 제약을 무시한 **낙관적 상한**이고, 실제로는 더 나쁘다.

## 5. 놓치기 쉬운 것

| | |
|---|---|
| **중개형** | ETF를 직접 매매하려면 중개형이어야 한다. 신탁형·일임형은 불가 |
| **한도는 납입액 기준** | 1억을 넣어 12억이 돼도 전액 ISA 혜택. **평가액 한도가 아니다** |
| **미납분 이월** | 매달 균등하지 않아도 되고 몰아넣어도 된다 (v26 §2 — 불규칙 납입 무해) |
| **3년 의무보유** | 그 전에 해지하면 세제혜택 상실, 일반과세로 추징 |
| **종합과세 제외** | ISA는 분리과세. 일반계좌였다면 연 2천만원 초과분이 누진 대상 |
| **4종 전부 ISA 가능** | 418660 / 458730 / 305080 / 411060 모두 국내 상장이라 편입된다 |
| **자격 요건** | 서민형은 총급여·종합소득 기준이 있다. 가입 전 직접 확인 |

**초과 자금이 있으면** ISA를 먼저 채우고 나머지를 일반계좌로 보낸다.
전환이 잦은 이 전략은 과세이연 효과가 가장 크므로 ISA 우선순위가 높다.

## 6. 화면(signal.html) 반영

### 추가한 것

- **계좌 패널** — 3칸 요약(실효세율 9.9% / 일반계좌 대비 +48.8% / 이득의 82%는 과세이연),
  계좌 4종 비교표, **선택지 3개**, 놓치기 쉬운 것 6줄
- **상단 고정 요약바** — 신호 패널이 화면 밖으로 나가면 `공격·QLD / 규칙 / 낙폭`을 상단에 고정.
  긴 화면을 스크롤할 때 지금 상태를 잃지 않는다 (모바일에서 특히)
- **v27 반영** — 방어 바스켓 `비중 고정 — 셋을 다 삽니다`, 이유 한 줄(도피 구간 9.3% vs 8.6%)
- **v28 반영** — 국내 ETF 종가로 판정하면 낙폭을 3%p 얕게 보고 −92%가 되는 이유 한 줄

### 고친 것

- 기존 세금 문단이 **배당100 시절 수치**(2,705→1,062배)였다. 현행 40/40/20 기준으로 갱신하고
  계좌 패널로 넘겼다

### UI (PC·모바일 공통)

| 항목 | 내용 |
|---|---|
| iOS 확대 방지 | 입력창 `font-size:16px` — 16px 미만이면 포커스 시 사파리가 화면을 확대한다 |
| 탭 타깃 | 모바일 버튼·파일라벨 `min-height:44px`, 칩 패딩 확대 |
| 지표 그리드 | 모바일에서 5칸 → **2칸**. 좁은 화면에서 숫자가 뭉개지지 않는다 |
| 표 가로스크롤 | `-webkit-overflow-scrolling:touch` + `← 표를 옆으로 밀어 보세요` 안내(모바일만) |
| 여백 | 모바일 좌우 20px → 13px, 패널 패딩 축소 |
| 중간 폭 | 601~820px에서 요약 3칸 → 2칸 |
| 기타 | `color-scheme:light` 명시(브라우저 자동 반전 방지), 마스트헤드 모바일 세로 정렬 |

### 검증

- 375px / 1280px 양쪽에서 **가로 넘침 0, 클리핑 0, 콘솔 오류 0**
- 고정 요약바 토글 로직: 스크롤 0/700 → off, 1500/3000 → on, 복귀 → off
- ISA 수치는 **HTML에 인라인**이다. 새 JSON을 받아오지 않으므로 `pages.yml` 수정이 필요 없다
  (v25에서 `kr_holidays.json` 복사 누락으로 라이브에서 404가 났던 실수를 되풀이하지 않기 위함)
