## 1. 3.2년 안에서 실제로 무슨 일이 있었나

### 1-1. 두 전략은 98.8% 의 날에 같은 자산을 들었다

A 와 B 는 **진입선이 −16% 로 같다.** 다른 건 복귀선뿐이다. 그래서 차이는
**B 가 먼저 공격으로 돌아가 있는 구간**에서만 생긴다.

| | 일수 | 기여 |
|---|---:|---:|
| 같은 자산을 든 날 | **750일 (98.8%)** | **−0.20%** ← 전환비용 차이만 |
| 갈린 날 | **9일 (1.2%)** | **−6.73%** |
| 합계 검산 | 759일 | **−6.92%** = 실제 B/A−1 **−6.92%** ✓ |

### 1-2. 전환이 전부 2025년 4월 한 달 안에 있었다

| B −16/−16 | A −16/−11 |
|---|---|
| 2025-04-04 방어 | 2025-04-04 방어 |
| 2025-04-10 공격 | |
| 2025-04-11 방어 | |
| 2025-04-14 공격 | |
| 2025-04-17 방어 | |
| 2025-04-24 공격 | 2025-05-02 공격 |

**B 6회 / A 2회.** 2025년 4월은 관세 발표로 나스닥이 며칠 만에 −16% 를 오르내린
구간이라 B 가 문턱을 네 번 더 넘나들었다. **그 외 3년 동안 전환은 0회다.**

### 1-3. 갈린 9일의 내역 — 두 번 지고 한 번 크게 이겼다

| # | 구간 | 일수 | B | A | B−A |
|---|---|---:|---:|---:|---:|
| 1 | 2025-04-11 | 1 | −9.2% | −1.7% | **−7.5%p** |
| 2 | 2025-04-15 ~ 17 | 3 | −8.0% | +0.5% | **−8.5%p** |
| 3 | 2025-04-25 ~ 05-02 | 5 | **+11.5%** | +1.1% | **+10.3%p** |

**두 번의 성급한 복귀(−16%p)를 한 번의 반등 포착(+10.3%p)이 거의 다 메웠다.**
남은 −6.7% 가 3.2년 성적표의 전부다.

> **"압도적"이 아니다.** 3년 성과의 차이가 **9일**에서 나왔고, 그 9일은 2승 1패가
> 아니라 **1승 2패**였을 뿐이다.

## 2. 54년으로 넓히면 — B 는 "자주" 이기지 않는다. "크게" 이긴다

같은 선행구간을 54년 전체에서 뽑았다. **70개.**

| | |
|---|---:|
| B 가 이긴 구간 | **25개 / 70개 = 36%** |
| 기여 **중앙** | **−1.3%p** |
| 기여 **평균** | **+1.1%p** |
| 표준편차 | 6.4%p |
| 최악 | −11.2%p (2000-09-01) |
| 최고 | +15.2%p (1992-08-28) |

**이게 핵심이다.** B 는 선행구간의 **64% 에서 진다.** 중앙값도 마이너스다.
그런데 **평균은 플러스**다 — 이기는 판이 훨씬 크기 때문이다.

| 가장 좋은 5개 (B 승) | | 가장 나쁜 5개 (A 승) | |
|---|---:|---|---:|
| 1992-08-28 | **+15.2%p** | 2000-09-01 | −11.2%p |
| 1988-06-07 | +13.7%p | 2025-04-10 | −7.3%p |
| 2025-04-24 | +11.5%p | 2020-03-11 | −6.8%p |
| 2011-08-23 | +11.4%p | 2000-07-21 | −6.4%p |
| 1986-10-02 | +11.0%p | 1988-04-12 | −6.2%p |

**B 의 우위는 "빨리 돌아가는 게 대개 옳아서"가 아니다.**
**대개는 조금 틀리고, 가끔 크게 맞아서다.** 바닥에서 반등할 때 한 번 잡으면
그 한 번이 여러 번의 헛발질을 덮는다.

> **그래서 짧은 표본에서는 A 가 이기기 쉽다.** 큰 승리 한 번이 안 들어오면
> 남는 건 잔손실뿐이다. 2023-2026 이 딱 그 모양이었는데, 그마저도
> 4월 25일 반등을 잡아 대부분 만회했다.

## 3. 그래서 3.2년으로 결론을 낼 수 있는가 — 없다

### 3-1. 선행구간 3개는 동전 세 번이다

54년 분포에서 무작위로 n 개를 뽑았을 때:

| 선행구간 n개 | A 가 더 좋아 보일 확률 | 누적 중앙 |
|---:|---:|---:|
| 1 | 64.0% | −1.0% |
| 2 | 46.9% | +1.7% |
| **3** ← 실물 3.2년 | **40.5%** | +2.7% |
| 5 | 39.5% | +3.8% |
| 10 | 32.9% | +9.0% |
| **19** ← 판단 최소치 | **26.4%** | +18.1% |
| 70 (전체) | 10.5% | +90.0% |

**순전한 운으로 A 가 이길 확률이 40%다.**

### 3-2. 3.2년 창은 54년 내내 A 가 자주 이긴다

| 창 길이 | 창 개수 | B 승률 | B−A 중앙 | 5분위 |
|---|---:|---:|---:|---:|
| **3년** | 625 | **61.1%** | +3.4% | −16.2% |
| 5년 | 601 | 76.5% | +9.0% | −16.2% |
| 10년 | 541 | **78.4%** | +16.0% | −18.9% |
| 20년 | 421 | 73.4% | +8.8% | −3.7% |

**3.2년 창 622개 중 A 가 이긴 창이 232개(37%)다.** 드문 일이 전혀 아니다.
반면 **10년으로 늘리면 B 가 78% 이긴다.**

### 3-3. 판정

```
[실물 3.2년의 A 우세가 규칙을 바꿀 근거가 되는가] 판정: 기각
  X  선행구간 표본이 판단 최소치(19) 이상     3개
  X  우연으로 뒤집힐 확률이 5% 미만          40%
  O  54년 선행구간에서 A 가 앞선다           중앙 -1.3%p, B 승률 36%
  X  3.2년 창 대부분에서 A 가 앞선다         B 승률 63%
```

**관문 4개 중 3개 미통과.** 유일하게 통과한 것(중앙값)이 §2 에서 설명한
**왜도** 때문이며, 그것만으로는 최종 금액에서 지는 규칙을 채택할 수 없다.

## 5. 화면 — 종가와 별개로 '전략 개정 시점'을 표시한다

> **사용자 요청: "html에 최종 수정이 언제됐는지도 알려주면 좋겠어. 종가수정 말고,
> 이 html 자체를 수정한게 언젠지 알아야 진짜 최신전략이 반영된건지 알 수 있잖아"**

제목 오른쪽에 두 줄로 나눠 적는다:

```
2026-08-26 종가 기준 · 자동갱신 8/27 14:38 KST     <- 데이터
전략 반영 2026-08-27 (a1b142a)                     <- 화면 로직
```

**값은 손으로 적지 않는다.** `deploy/stamp_rev.py` 가 배포 때
`git log -1 -- signal.html` 로 읽어 박는다. 손으로 적으면 반드시 어긋난다(v45 §2 의 교훈).

치환 자리를 못 찾으면 **배포가 실패한다.** 조용히 빈 값이 나가지 않는다.
로컬 사본을 그냥 열면 **"로컬 사본 — 배포본이 아닙니다"** 가 빨간 글씨로 뜬다.

## 6. 글꼴 — 전부 Pretendard, 모든 크기 +4px

| | 전 | 후 |
|---|---|---|
| 본문 | Pretendard | Pretendard |
| 숫자·라벨 | IBM Plex Mono | **Pretendard** + `tabular-nums` |
| 제목 | Archivo | **Pretendard** |
| 크기 | 9~21px | **13~25px** (전부 +4) |
| 큰 판정 글씨 | clamp(34,7vw,52) | clamp(38, 7.6vw, 56) |

`tabular-nums` 로 **숫자 자릿수 정렬은 그대로 유지**된다(고정폭 글꼴을 버려도 표가 안 흔들린다).

**입력창 16px 는 안 키웠다** — iOS 사파리가 16px 미만 입력창에 포커스하면 화면을 확대한다.

### 레이아웃 — 글자가 커진 만큼 자리도 넓혔다

눈금 라벨 38→50px · 신호판 132→156px · 시계 78→94px · 본문폭 920→1020px ·
표 최소폭 600→700px / 480→560px

**폰(≤600px)과 태블릿(601~900px)에서는 지표를 4칸 → 2칸으로 접는다.**

검증: 375 / 768 / 1280px 에서 **가로 넘침 0px**, 콘솔 오류 0건.
