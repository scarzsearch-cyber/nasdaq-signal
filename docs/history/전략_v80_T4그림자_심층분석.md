## 1. 구현·기록 건전성 (A)

- **장부 구현 검산 통과**: `deploy/oos_log.py t4_shadow()` vs pandas 독립 계산,
  최근 250세션 **불일치 0건**. 최신행(08-28: votes 3 · rv 36.7 · w 1.0) 재계산 일치.
- **종가 원천 이원화(미결① 의 T4 판)**: `data/qqq.csv` vs 연구용 `qqq_us_d.csv` 로
  각각 신호를 만들면 게이트(votes≥2) 불일치 **0.04% 일수** — 실질 영향 없음.
- **v68 재현**: 방어 규약은 **T-bill**(cash='tbill') 로 확인 — MDD 오차 0.03%p/0.00%p
  (T4 −53.4% · B −63.1% 정확 재현). 최종배수는 T4 +5.1% / B +1.4% 잔차 —
  사전 허용치(±5%)를 T4 가 0.1%p 넘었다. v68 의 백테스트 코드는 커밋되지 않아
  (문서만 남음) 잔차 분해가 불가능하다. **이 스크립트가 이제 저장소 내 유일한
  실행 가능 참조 구현이다.**
- **기록 견고성 빈틈 1건 → 이행 완료**: `t4_shadow()` 가 `qqq.csv` 마지막 날짜와
  `as_of` 의 일치를 확인하지 않아, 가격 append 만 실패한 날은 **전일 값이 오늘
  날짜로 그럴듯하게** 기록될 수 있었다. 마지막 행 날짜 == as_of 가드를 넣었다
  (불일치 시 경고 + 빈 칸 — 파라미터·정상 경로 무변경, 정상일 재계산 값 불변 확인:
  08-28 (3, 36.7, 1.0) · 08-27 (3, 36.3, 1.0) = v69 검산값). 부수로 구판 주석의
  "(비수정)" 오기를 정정했다 (`update_signal.py` 는 Yahoo **수정주가** 캐시 유지).

## 2. 기전 해부 (B) — 어디서 벌고 어디서 잃나

| 항목 | 값 |
|---|---|
| 노출 분포 | w=0 **19.3%** · 중간 21.2% · w=1 59.5% 일수 (평균 0.75, B 0.82) |
| 회전 | 연 7.3 (B 2.6) — **게이트 전환 기인 81%** · 변동성 조정 19% |
| 게이트 | 전환 연 7.3회 · votes==2 경계 체류 14.7% 일수 |
| lag 민감도 | lag=2 에서 최종 163,161→**74,523 (−54%)** (MDD 는 여전히 B 보다 좋음) |
| 비용 민감도 | 편도 0.1% 격차 −4% → 0.2% **−26%** → 0.3% −43% |

**위기별 MDD — T4 의 급락 우위는 보편이 아니다**: 1987·코로나·2022 는 T4 승,
**닷컴(−53.4 vs −47.0)과 2008(−45.9 vs −40.3)은 B 승.** 사건 단위로는 17/22 (77%).
연도 기여 최악은 1999(−0.38) — 고변동 상승장에서 변동성 타깃이 노출을 깎는 비용.

**기전 직접 측정 (신규)** — 독립 도피 사건 22회 (252거래일 초과 간격 기준):

| 측정 | 기저율 |
|---|---:|
| B 도피일에 T4 노출이 이미 < 0.7 | 19/22 (**86%**) — 도피일 노출 중앙 0.00 |
| **M1** 도피 직전 10일 평균 노출 < 0.7 | 16/22 (**73%**) — 문턱 0.5 면 14/22 (64%) |
| **M2** 사건창(도피 −63~+252 거래일) MDD T4 우위 | 17/22 (**77%**) |
| M1 ∧ M2 동시 성립 | 14/22 (**64%**) |
| M1 · M2 둘 다 실패 | 3/22 (**14%**) |

"급락 전 사전 감속"은 실측되는 기전이고, **사건 단위로 동전(50%)과 구별된다.**

## 3. ★ 판정 규약 전력 분석 (C) — v69 규약을 과거 3년 창 569개에 소급 적용

| | 3년 창 (n=569) | 5년 창 (n=597) |
|---|---:|---:|
| 사건(dd≤−16%) 포함 비율 | 91% | 99% |
| (a) MDD·Calmar 둘 다 우위 | **53%** | 52% |
| (a)+(b) 승, −29% 한도 | 53% | 50% |
| (a)+(b) 승, −8% 한도 | 49% | 44% |
| (a)+(b) 승, 한도 연율화(−0.63%/yr) | 43% | — |
| 대형 위기(dd≤−30%) 창 한정 | 53% | 50% |
| 한도 해석(−8 vs −29)에 뒤집힘 | 4% | 6% |
| 보완자산(T-bill vs SCHD)에 뒤집힘 | 1% | 1% |

**결론: 창 단위 총성적 비교는 어떤 변형으로도 동전던지기다.** 3년을 5년으로 늘려도,
대형 위기로 한정해도, 한도를 연율화해도 승률 43~53%. v70 §3 의 "본거지 수익은 판별
불가(47.4%)"가 **v69 규약의 위험조정 기준에도 그대로 옮는다** — 창의 Calmar·MDD 비교는
그 창에 어떤 국면(변동성 급락형이냐 닷컴형이냐)이 왔는지를 재는 것이지 전략의 장기
우열을 재지 못한다. 반면 모호점 2개(한도 해석·보완자산)는 실측 4%/1% 로 무해했다.
**판별력은 사건 단위 기전 관문(§2 표: 73~77% vs 동전 50%)에 있다** — 그리고 그 관문은
이미 기록 중인 열(t4_w · close · state)만으로 계산된다. 장부 변경 불필요.

## 4. 집행층 개선 시도 (D) — 무거래 밴드, **기각**

신호·기록 열 불변으로, 판정 재구성 규약에만 속하는 무거래 밴드(|목표−보유|≤밴드면
매매 생략)를 사전 기준(0.2% 비용에서 최종·Calmar 유지 + **연회전 ≤60%** + 고원)으로
스윕했다. **탈락** — 회전의 81%가 게이트 전환(0↔w 점프)이라 밴드 20%로도 회전이
7.3→6.3 (−14%)뿐이다. band 15% 의 최종 +18.4% 는 이웃(+9.1%/+3.1%)과 비단조라
경로 잡음으로 판정. 주1회 재조정은 재앙(최종 −68%, MDD 악화 — 게이트 지연은 lag=3
과 같은 효과). **T4 의 비용 문제는 집행이 아니라 신호 구조(투표 게이트)에 있고,
신호는 동결이므로 손대지 않는다.**

## 6. ★ 판정 규약 부속서 (2026-08-29 등록 — 이후 수정 금지)

**6-1. 재구성 규약 (v69 의 미고정 사항 확정)**

- T4 의 (1−w) 보완자산: 실측 NAV 가 없으면 T-bill. (실측 기반 재구성이면 자동 해결.
  민감도 실측 1% — 어느 쪽이든 판정 불변.)
- (b)의 한도는 **−29% (판정 창 누적, 원화 실측)** 하나로 고정. −8% 해석은 폐기
  (재구성이 원화 실측이므로 한국 실효비용 교환비가 해당 값). 이 한도는 연율 평균이
  아니라 **극단 출혈 방지 가드**다 — 3년 창 역사 분포(중앙 +3.2% · 5분위 −41%)의
  대략 P10. 연율화(−0.63%/yr)는 승률 43% 의 또 다른 동전이라 채택하지 않았다.

**6-2. 사건 단위 기전 관문 (신설)**
- 사건 정의: 장부 `state` 가 QLD→SCHD 로 바뀐 도피 신호일. 직전 도피와 252거래일
  초과 간격이면 독립 사건.
- **M1 사전 감속**: 도피 신호일 직전 10개 장부행의 `t4_w` 평균 < **0.7**.
  (역사 기저율 73%. 문턱 0.5 는 64% — 민감도 기록용, 관문은 0.7 하나만.)
- **M2 사건창 방어**: 도피일 −63 ~ +252 거래일 재구성 NAV 의 MDD 에서 T4 우위.
  (역사 기저율 77%. +252일이 차기 전에는 그 사건을 판정에 쓰지 않는다.)

**6-3. 판정 결합 (판정 시점은 v69 그대로: ≥3년 그리고 독립 사건 ≥1회)**
- **종료 (기전 불발)**: 모든 독립 사건에서 M1·M2 둘 다 실패.
  (기전이 역사처럼 작동한다면 단일 사건에서 둘 다 실패할 확률 14%.)
- **종료 (출혈)**: 원화 총수익 열세가 −29% 초과 — 사건 결과와 무관하게 즉시.
- **승 (교체 검토 개시)**: 독립 사건 과반에서 M1∧M2 성립 (역사 기저율 64%)
  **그리고** 기존 (a) MDD·Calmar 우위 **그리고** (b) 열세 ≤ 29%.
- **그 외**: 유보 — 다음 독립 사건의 +252일 창이 찬 뒤 재판정. 유보 중에도
  출혈 종료 조항은 살아 있다.
