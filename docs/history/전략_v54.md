```

```

## 4. 새로 확인된 음성 결과 세 개

### 4-1. 국채 flight-to-safety 는 아무것도 없다 (D, 8개 변형)

**이 축은 1962년부터 4블록 전부 검증 가능했다.** 데이터 제약이 없었는데도
**8개 변형 전부 4블록 0/4** 이고 P20·P5 가 −20~25% 다.

금리 20일 변화, 장단기차(10년−3개월), 금리충격 후 정상화 — 전부.

> **"주식이 빠질 때 국채가 오르면 전형적 안전자산 도피, 같이 빠지면 금리쇼크"**
> 라는 구분은 **복귀 타이밍에 아무 정보를 주지 않는다.**

### 4-2. 시장 내부구조(NYA)도 아무것도 없다 (B, 4개 변형)
