## 1. v21 의 추론 오류 두 개

### 오류 ① — 상대 변화율을 절대 순위로 착각

v21 §4.3 의 자기 표다:

| | A −16/−11 | B −16/−16 |
|---|---:|---:|
| ① 기존 규약 | 1,137.5 | **1,426.1** |
| ② + 한국 거래일 매핑 | 1,108.9 (−2.5%) | **1,316.1** (−7.7%) |
| ③ + 편도 0.1% 슬리피지 | 1,078.3 (−2.8%) | **1,241.8** (−5.6%) |

**세 줄 모두 B 가 높다.** 마찰을 다 물린 뒤에도 1,241.8 vs 1,078.3 으로 **B 가 15% 앞선다.**

그런데 v21 의 결론은 이랬다:

> "한국 마찰은 B 를 A 보다 2~3배 더 깎는다. **이는 −16/−11 유지 쪽 증거다.**"

**「B 가 더 많이 깎인다」를 「A 가 낫다」로 읽었다.** 깎이고도 B 가 이기고 있는데.

### 오류 ② — 표준편차와 평균비용을 직접 비교

> v21 §4.4: "레버리지 상품의 표준편차 2.58% ... 이는 거래비용 0.1% 보다 **26배** 크다.
> 전환 횟수를 줄이는 것이 비용 자체를 줄이는 것보다 훨씬 중요하다"

**단위가 다른 둘을 비교했다.**

| | 정체 |
|---|---|
| 0.1% | 매번 확실히 나가는 **평균 비용** |
| 2.58% | 방향이 없는 **표준편차** |

v21 본문도 "갭 자체는 방향성이 없어 매수·매도에 평균적으로 상쇄된다"고 적어 뒀다.
**방향 없는 분산의 실제 비용은 변동성 손실 σ²/2 = 0.033%/회다.**
0.1% 보다 26배 큰 게 아니라 **3분의 1**이다.

## 2. 실측 — 마찰을 전부 물려도 B 가 이긴다

### 2-1. 슬리피지 스윕 (한국 거래일 체결, 1997-2026, 프로젝트 엔진 `run_kr`)

| 편도 슬리피지 | B −16/−16 | A −16/−11 | B/A |
|---|---:|---:|---:|
| 0.0% | 2,926.5 | 2,223.3 | 1.32 |
| **0.1% (실제 가정)** | **2,761.3** | **2,161.9** | **1.28** |
| 0.5% | 2,187.5 | 1,931.9 | 1.13 |
| **1.0%** | 1,632.8 | 1,677.5 | **0.97** ← 여기서 역전 |
| 2.0% | 905.6 | 1,262.1 | 0.72 |

**A 가 이기려면 슬리피지가 편도 1.0% 여야 한다.** 실제 가정(0.1%)의 **10배**다.
전환 횟수는 B 62회 / A 28회.

### 2-2. 갭 분산 몬테카를로 (전환마다 N(0, 2.58%), 2000회)

v21 이 실측한 갭 표준편차를 전환마다 무작위로 물렸다.

| | 중앙 | 5분위 | 95분위 |
|---|---:|---:|---:|
| **B** | **2,718** | **1,923** | 3,811 |
| A | 2,141 | 1,698 | 2,663 |

| | |
|---|---:|
| **B 가 A 를 이긴 비율** | **83.6%** |
| 갭 없을 때 B/A | 1.28 |
| **갭 반영 후 B/A** | **1.27** |
| 변동성 손실 | B 1.6% / A 1.0% (**차이 0.6%p**) |

**갭을 물려도 1.28 → 1.27.** 29년 누적 0.6%p 차이면 연 0.02% 다.
v21 이 "26배 크다"고 본 것의 실제 크기가 이것이다.

### 2-3. 남는 반대 증거 — 실물 TIGER 구간

| | 최종 | MDD | Calmar | 전환 |
|---|---:|---:|---:|---:|
| B | 2.9배 | −44.9% | 0.868 | 6회 |
| **A** | **3.1배** | **−37.0%** | **1.141** | 2회 |

**2023-06 ~ 2026-08, 3.2년.** 여기서는 A 가 이긴다.
다만 **전환이 6회 대 2회**다. v41 기준(독립 위기 19회가 최소 표본)으로 보면
여기는 1~2회짜리 표본이라 판단 근거가 못 된다. **기록만 해 둔다.**

## 3. 보조전략 탐색 — 쓸 만한 게 없다

### 3-1. 낙폭 문턱 변형은 전부 B 와 중복이다

| 후보 | 상태 일치 | 수익 상관 | B 부진창서 | 전체 승률 |
|---|---:|---:|---:|---:|
| A −16/−11 (현행 보조) | **96%** | **0.99** | −30% | 6% |
| −19/−18 | 97% | 0.99 | −8% | 57% |
| −16/−15 | **99%** | **1.00** | 0% | 35% |
| −23/−7 | 95% | 0.97 | −20% | 57% |
| −11/−11 | 91% | 0.92 | **+44%** | 16% |
| −12/−6 | 85% | 0.92 | −1% | 13% |

**같은 신호(QQQ 252일 낙폭)에 문턱만 다르니 상관이 0.92 밑으로 안 내려간다.**
−16/−15 는 상태 일치 99%, 상관 1.00 — 사실상 같은 전략이다.

### 3-2. 유일한 저상관 후보 −11/−11 은 시대 전용이었다

"B 부진창에서 +44%" 로 보여 유일한 보완재처럼 보였다. 쪼개보니 아니다.

| 구간 | −11/−11 | B | 차이 |
|---|---:|---:|---:|
| 1972-85 | 21.4배 | 14.0배 | **+53%** |
| 1986-99 | 42.7 | 81.8 | −48% |
| 2000-13 | 4.2 | 7.3 | −42% |
| 2014-26 | 11.2 | 25.5 | −56% |

**2000년 이후 시작 20년 창 27개 중 −11/−11 이 이긴 건 0개다.** 중앙 −73%.

"B 부진창" 35개의 절반 이상(19개)이 1970년대 시작 창이었다.
**+44% 는 거기서 나온 값이고, 2000년대 창 13개에서는 0승이다.**

## 5. 판단 기준에 추가 (중요)

v21 의 오류는 오늘 분류한 **④ 검증 설계 오류**와 같은 계열이다.
`research_kit` 체크리스트에 두 항목을 추가한다.

- [ ] **상대 변화율을 절대 순위로 읽지 말 것.**
      "A 가 B 보다 덜 깎인다" ≠ "A 가 낫다". 깎인 뒤 누가 앞서는지 봐라.
      v21 이 이걸로 21년 묵은 잘못된 권고를 남겼다.
- [ ] **표준편차를 평균비용과 직접 비교하지 말 것.**
      방향 없는 분산의 실제 비용은 **σ²/2** 다. 2.58% 표준편차는
      회당 0.033% 이지 2.58% 가 아니다.
