### §19 의 분류 — **Case B**

| | |
|---|---|
| Case A: Oracle >> 고정, 메타 ≈ Oracle | 동적 선택에 가치 있음 → **아니다** |
| **Case B: Oracle >> 고정, 메타 ≈ 고정** | **← 이것** |
| Case C: Oracle ≈ 고정 | 전환 가치 자체가 작음 → 아니다 (+288%) |
| Case D: 메타 < 고정 | 해롭다 → 6/7 이 여기 (−11~80%) |

> **시대별 최적 규칙은 존재하지만(Oracle +288%), 그 시대가 시작될 당시
> 알 수 있었던 정보로 그것을 알아낼 방법이 없다.**
>
> 실제로는 **Case B 와 D 의 중간** — 메타 7종 중 6종이 고정보다 **나쁘다.**

## 7. 최종 — **현행 −16/−16 유지**

> **고정 −16/−16 을 시대별로 동적으로 바꾸는 추가 복잡성이
> 실질적인 성과 개선으로 이어지지 않았다.**

이 결과는 v56 의 미니맥스 발견과 **정합적이다.**
현행이 어느 시대에서도 1등이 아니면서 어디서도 무너지지 않는 것은
**"어느 시대가 올지 모른다"는 상황에서 합리적인 선택**이다.
그리고 v58 은 **그 시대를 미리 알 방법이 없음**을 직접 확인했다.

**동결 원칙 유지** — 2026-08-27 이후 데이터는 이 연구에 쓰지 않았고, 앞으로도 쓰지 않는다.
