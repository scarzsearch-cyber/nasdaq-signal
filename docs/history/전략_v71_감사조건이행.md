## 조건 ① — B-1 해소: 라이브 신호를 수정 종가로 통일

**문제 (v67 B-1)**: 백테스트·공표 수치는 수정 종가(`qqq_us_d.csv`), 라이브 신호·OOS
장부는 비수정 종가로 낙폭을 계산했다. 27년 중 11일 신호 불일치 — 운용 중인 규칙이
검증된 규칙과 달랐다.

**조치**: `deploy/update_signal.py` 가 Yahoo chart 의 `adjclose`(배당 조정 수정 종가)를
쓰도록 변경. `data/qqq.csv` 전체 재작성 (1999-03-10 첫값 51.06 → 43.03).

**검증**:
- 야후 수정 종가 vs 백테스트 수정 종가: **6,908일 전체 신호 불일치 0일** (낙폭 차
  평균 0.002%p). 비수정은 11일 갈렸다.
- 최신 봉은 수정 == 비수정이라 화면 종가 표시는 불변 (721.11). 낙폭만 기준 통일로
  −3.36% → −3.25%.
- 네이버 예비 소스(비수정)와의 정합: 최신 봉은 항상 수정==비수정이므로 붙여도 일관.
  Yahoo 장기 장애 중 배당락이 겹치는 예외는 복구 시 전체 이력 재수신으로 자동 정정.
- OOS 장부 첫 행(08-28 종가)부터 통일된 기준으로 기록된다 — 장부에 혼합 기준 없음.
- `verify_all.py` 에 회귀 방지 추가: `신호원이 수정 종가(adjclose)다`.

**동결과의 관계**: freeze.json 의 "QQQ 미국장 종가"는 수정/비수정을 특정하지 않았다
(사양 공백). 이 조치는 규칙 변경이 아니라 **백테스트가 검증한 기준으로의 명확화**다.
freeze.json 은 건드리지 않았다.
