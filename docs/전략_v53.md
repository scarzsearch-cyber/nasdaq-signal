## 1. 규칙

```
진입:  DD ≤ −16%  →  방어                     (현행 그대로)
       그 순간 21일 실현변동성의 3년 z 를 **한 번만** 읽는다
복귀:  진입 시 z >  0.25 (변동성 있음) →  DD > −16% 에서 복귀 (현행)
       진입 시 z ≤ 0.25 (조용함)      →  DD > −11% 까지 기다린다
```

**기전 가설**: 조용히 시작된 하락은 구조적이라 얕은 회복이 가짜일 확률이 높다.
변동성과 함께 온 급락은 V자로 튄다 → 현행처럼 빨리 돌아간다.

실현변동성과 VIX 의 상관은 **0.675** — 같은 것이 아니라 대용이다.
대신 **1972년까지 간다**는 게 v52 의 VIX 판과 결정적으로 다르다.

## 3. 그런데 — 우위의 87%가 2000년 두 사건이다

관문에는 없었지만 **v41 이 정한 규율**(독립 위기 19회가 최소 표본)을 적용했다.

두 규칙이 **갈린 구간 32개**를 뽑아 일별 로그차로 정확히 분해했다.

> **검산**: 구간별 기여 합계 **+21.49%** = 실제 최종 배수비 **1.2397** ✓

## 4. 판정 — 기각

```
관문 10/10 통과.  집중도 검사에서 탈락.
```

### 왜 관문을 통과했는데 기각인가

**관문이 불충분했다.** 10개 중 어느 것도 "**이득이 몇 개 사건에 몰려 있는가**"를
묻지 않는다. 승률(75%)과 중앙값(+1.81%)은 좋은데, **총합은 3개가 만든다.**

이건 v46 이 현행에 대해 밝힌 것과 **정반대 방향의 문제**다.
현행도 왜도가 크지만(선행구간 승률 36%, 평균은 플러스) 그 왜도는
**70개 구간에 퍼져 있다.** 이 후보는 **32개 중 3개**다.

### 관문에 추가한다

> **G7 집중도 — 상위 3개 사건을 빼도 세 지표가 모두 우세를 유지하는가.**

v53 이전의 후보들에도 소급 적용해야 하나, 전부 G1~G6 에서 이미 탈락해 순위가 안 바뀐다.
