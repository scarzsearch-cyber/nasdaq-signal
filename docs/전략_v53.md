## 0. 답

>
> **이 프로젝트 사상 처음으로 10개 관문을 전부 통과했다.**
> 중앙 +11% · P20 +4% · P5 +2% · MDD 개선 · 전환 −33% · 4블록 3/4 ·
> 파라미터 이웃 연속 5개 · 비용 5배 유지 · 창 간격 무관 · 연대별 3/4.
>
> **그런데 관문에 없던 검사 하나에서 무너졌다.**
>
> **상위 3개 사건의 기여 비중이 119%다** — 100%를 넘는 건 나머지 29개의 합이
> 마이너스라는 뜻이다. 상위 3개를 빼면 P5 가 **−4%** 로 뒤집힌다.
> **독립 위기로 세면 9개**로, v41 최소치(19회)의 절반이다.
> leave-one-crisis-out 에서도 **1980-82 · 1987 을 빼면 P5 가 마이너스**가 된다.
>
> **기각. 현행 −16/−16 유지.** 다만 **지금까지 나온 것 중 가장 강한 후보**로 기록한다.

## 1. 규칙

```
진입:  DD ≤ −16%  →  방어                     (현행 그대로)
       그 순간 21일 실현변동성의 3년 z 를 **한 번만** 읽는다
복귀:  진입 시 z >  0.25 (변동성 있음) →  DD > −16% 에서 복귀 (현행)
       진입 시 z ≤ 0.25 (조용함)      →  DD > −11% 까지 기다린다
```

**기전 가설**: 조용히 시작된 하락은 구조적이라 얕은 회복이 가짜일 확률이 높다.
변동성과 함께 온 급락은 V자로 튄다 → 현행처럼 빨리 돌아간다.

실현변동성과 VIX 의 상관은 **0.675** — 같은 것이 아니라 대용이다.
대신 **1972년까지 간다**는 게 v52 의 VIX 판과 결정적으로 다르다.

### 3-1. Gate 11 정식 판정 (`research_kit.concentration`)


**상위 3개 비중이 119% 다.** 100% 를 넘는 건 **나머지 29개의 합이 마이너스**라는 뜻이다.

**독립 위기는 9개다.** 32개 사건이 1988년에 6개, 1992년에 4개, 2000년에 4개 식으로
군집해 있다. v41 이 정한 최소치 **19회**의 절반이다.

## 4. 판정 — 기각

```
관문 10/10 통과.  집중도 검사에서 탈락.
```

### 왜 관문을 통과했는데 기각인가

**관문이 불충분했다.** 10개 중 어느 것도 "**이득이 몇 개 사건에 몰려 있는가**"를
묻지 않는다. 승률(75%)과 중앙값(+1.81%)은 좋은데, **총합은 3개가 만든다.**

이건 v46 이 현행에 대해 밝힌 것과 **비슷해 보이지만 규모가 다르다.**
현행도 왜도가 크지만(선행구간 승률 36%, 평균은 플러스) 그 왜도는
**70개 구간에 퍼져 있고 독립 위기 19회를 채운다.**
이 후보는 **32개 중 3개, 독립 위기 9개**다.

**그리고 닷컴 하나의 문제가 아니다.** leave-one-crisis-out 은
**1980-82 · 1987 · 2000-02 세 시대가 각각 지지대**임을 보여준다(§3-2).
어느 하나만 빠져도 P5 가 무너지거나 0 에 붙는다.

### 관문에 추가한다

> **Gate 11 — 성과 집중도.** `research_kit.concentration()` 과
> `research_kit.leave_one_crisis_out()` 으로 **코드에 박았다.**
> 기억에 의존하면 다음에 또 빠뜨린다 — 이 프로젝트의 교훈이
> "검산 함수가 있던 코드는 12건 중 0건이 틀렸다" 이다.

검사 항목:

| | |
|---|---|
| 갈린 사건 수 | 최소 표본 |
| **독립 위기 수** | 군집을 하나로 세어 v41 기준(19)과 대조 |
| 사건 승률 | 50% 초과 |
| 상위 1/3/5 제외 | 기여합이 양수로 남는가 |
| 상위 3개 비중 | 50% 미만인가 |
| **상위 1/3/5 제외 후 재시뮬** | 세 지표가 모두 우세를 유지하는가 |
| **leave-one-crisis-out** | 위기를 하나씩 빼도 유지되는가 |

`research_kit.py` 자기검사에 **집중된 후보는 막고 고른 후보는 통과시키는** 사례를 넣었다.
차단하는 설계 오류가 5종 → **6종**이 됐다.

v53 이전의 후보들에도 소급 적용해야 하나, 전부 G1~G6 에서 이미 탈락해 순위가 안 바뀐다.

## 5. 그래도 기록할 것 — 지금까지 가장 강한 후보다

| | v50 G | **v53 실현변동성 상태** |
|---|---|---|
| 통과 관문 | 4/6 | **10/10** |
| 파라미터 이웃 | 고립 첨탑 (3/5) | **연속 5개 능선** |
| MDD | −60.5% → **−63.3% 악화** | −60.5% → **−58.1% 개선** |
| 전환 | 140 → **256 증가** | 140 → **94 감소** |
| 4블록 | 실질 3승 1무 | 3승 1패 |
| 시대 의존 | 1970년대만 | 연대별 3/4 (창 기준) |
| 독립 위기 | — | **9개** (최소 19 미달) |
| **탈락 사유** | 첨탑 · MDD 악화 | **집중도 · 독립 위기 부족** |

**질적으로 다른 후보다.** G 는 집계 지표 여러 곳에서 흔들렸고,
이건 집계 지표는 전부 통과하고 **표본의 두께**에서만 부족하다.

**그래서 "실패한 전략"이 아니라 "검증이 부족한 전략"으로 분류한다.**
표본이 늘면 결론이 바뀔 수 있는 유일한 후보다.
